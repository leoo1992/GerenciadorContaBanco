# Gerenciador de Conta Bancária

Exercício de Java para simular operações básicas de uma conta bancária por meio de entrada e saída no terminal.

## Stack
- Java
- Programação orientada a objetos

## Como executar
Abra o projeto `ContaBanco` em uma IDE Java, configure um JDK e execute a classe `ContaNoTerminal`, em `ContaBanco/src/ContaNoTerminal.java`.
